      Téléphone en Wi-Fi

      Le plus simple : téléphone branché en USB et sur le même Wi-Fi que le PC → un clic, puis tu débranches le câble. (À refaire après un redémarrage du téléphone.)

      Sans câble : associer avec un code (Android 11 et plus)
      1. Sur le téléphone : Options pour les développeurs → Débogage sans fil → activer.
      2. Touche « Associer l'appareil avec un code d'association ».
      3. Recopie ici l'adresse IP et port de cette fenêtre et le code à 6 chiffres.

      Déjà associé ? Connecte-toi avec l'adresse et le port affichés en haut de « Débogage sans fil » :
